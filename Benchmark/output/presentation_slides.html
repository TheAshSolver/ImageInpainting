Benchmarking Methodology

Strategy B: Thermal Hysteresis Ramp-Up & Down

Eliminates 15+ minutes of passive cooldown delays by interleaving NPU heating with GPU cooling sweeps.

1. Alternating Sweeps

• Config 1: MIGAN (NPU) ▲ 33°C → 60°C (81 pts)

• Config 2: MIGAN (GPU) ▼ 60°C → 33°C (57 pts)

• Config 3: LaMa (NPU) ▲ 33°C → 60°C (69 pts)

• Config 4: LaMa (GPU) ▼ 60°C → 33°C (51 pts)

• Config 5: AOT-GAN (NPU) ▲ 33°C → 60°C (66 pts)

• Config 6: AOT-GAN (GPU) ▼ 60°C → 33°C (51 pts)

2. Active Thermal Injection

• In-process 4-worker Oryon CPU booster (boostTemperatureTo).

• Ramps silicon rapidly at 1.5 seconds per 1°C.

• 150 ms stabilization window ensures CPU cores idle before pure inference measurement.

3. Natural Cooling Descent

• Fast high-ΔT radiative dissipation at higher temperatures.

• Samples continuous GPU inferences as temperature falls back to ambient.

• Captures directional hysteresis between forward and reverse thermal cycles.

Reinforcement Learning

LinUCB Contextual Bandit Policy

Disjoint LinUCB router optimizing engine selection in real time under dynamic thermal and power drift.

Mathematical Formulation

• Context Vector:
x_t = [1, T_t (°C), U_t (%), V_t (V)]^T ∈ ℝ⁴

• Precision Matrix & Vector:
A_a = ∑ (x_t x_t^T) + λ I ∈ ℝ⁴ˣ⁴
b_a = ∑ (r_t x_t) ∈ ℝ⁴

• Ridge Parameter Estimate:
θ̂_a = A_a⁻¹ b_a

• Upper Confidence Bound Selection:
a_t = argmax [ x_t^T θ̂_a + α √(x_t^T A_a⁻¹ x_t) ]

Multi-Objective Scalar Reward

• Objective Function:
R(a, x) = 1.5*Q_a - 1.0*L_pen - 0.4*P_pen - 1.2*T_viol

• Quality Score Q_a: Benchmark SSIM/PSNR ranking (AOT: 1.0, LaMa: 0.90, MIGAN: 0.75).

• Latency Penalty L_pen: Latency normalized against 200 ms real-time ceiling.

• Thermal Violation Penalty T_viol: Heavy linear penalty when temperature exceeds 55°C ceiling.

Hardware Deep-Dive

Empirical 80°C Throttling & Device Tree Analysis

Kernel thermal zone inspection and high-temperature stress results up to 82°C.

Kernel Device Tree Trip Points

• Board Governor (sys-therm-0, Zone 66): 78.0°C Trip 2 actively throttles cooling devices.

• cooling_device38 (cdsp / NPU): 8 down-bin states (0..7) managing Hexagon DSP clocks.

• cooling_device35 (kgsl / GPU): 13 down-bin states (0..12) dropping Adreno 830 clock from 1,100 MHz to 222 MHz.

• Junction Sensors: Passive throttling at 105°C, critical cutoff at 135°C.

Slowdown & Degradation Factors

• Nominal (34°C–77°C): 0% throttling. NPU latencies remain rock-solid within ±1 ms.

• At 78.0°C (Trip 2 Triggered):

  – Adreno 830 GPU down-bins 1100 → 950 → 800 MHz (1.16× to 1.38× slowdown).

  – Hexagon HTP v79 NPU steps down DSP clock tier (1.10× to 1.25× slowdown).

• Takeaway: NPU remains drastically faster and more thermally resilient than GPU across all thermal regimes.
