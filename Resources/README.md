# Resources and References

This folder should contain all supporting resources used in the project. These materials help document the research, learning, and external support behind the implementation.

## 1. Resources to Include

Add any relevant materials such as:

- research papers,
- articles,
- technical documentation,
- online tutorials,
- datasets,
- reference links,
- design inspiration or background sources.

## 2. Documentation Requirements

Each resource should be documented clearly with:

- the title or name of the source,
- the author or organization,
- the URL or publication link,
- a short explanation of how it was used,
- why it was relevant to the project.

## 3. AI Usage Transparency

If AI tools were used for searching, summarizing, brainstorming, or code support, document this here as well.

Include:

- the AI tool used,
- the prompt or query used,
- a link to the related chat or discussion, if available,
- how the AI output influenced the project.

## 4. Reproducibility

The purpose of this section is to make the project traceable and reproducible. Anyone reviewing the repository should be able to understand where the ideas, references, and supporting information came from.

## 5. Final Check

Ensure that all external resources are properly cited and that any AI assistance is clearly explained in a professional and transparent manner.
